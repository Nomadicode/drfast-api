DRFast API documentation
=========================

DRFast API brings a Django REST Framework-inspired structure to asynchronous
FastAPI applications built with Tortoise ORM. It provides model base classes,
serializers, class-based views and CRUD viewsets, routers, permissions,
middleware helpers, and project commands without hiding the underlying FastAPI
or Tortoise APIs.

Use the guides in order for a new project, or jump directly to the feature you
need. The API reference documents the public package surface.
